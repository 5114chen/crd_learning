## 第一编：水下机器人结构（硬件）

### 第一章 水下机器人的开发和分类

#### 1.1 海洋与海洋开发
| 资源 | 要点 |
|------|------|
| 海洋规模 | 总面积 3.6×10⁸ km²（占地球 70.8%）；海水体积约 1.37×10⁹ km³；平均水深 3800 m，最深马里亚纳海沟 11034 m |
| 生物资源 | 海洋生物 16 万种以上，鱼类约 2 万种，约 1500 种可食用；我国海域生物 20278 种；海藻年增长量约 (1.3~1.5)×10¹¹ t，被视为未来蛋白质来源 |
| 矿物资源 | 海底油气占世界储量 1/3；深海多金属结核矿总储量 3.0×10¹² t（太平洋 1.7×10¹² t）；我国已在太平洋国际海底区域登记 15×10⁴ km² 开辟区 |
| 能源 | 潮汐能（法国朗斯河口、我国江厦电站）、波浪能（日本"海明"号 1000 kW）、温差/浓度差 |
| 热能 | 表层与深层海水温差发电（法国阿皮加电站 7200 kW、日产淡水 1.4 万吨） |
| 空间 | 海上城市、海底实验室、海上机场 |

#### 1.2 水下机器人的分类
- **载人潜水器**：由潜水球和潜艇技术微型化发展而来，配窥视窗、照明、水下电视、声纳、机械手，耐压舱容纳 2~3 人。
- **无人潜水器**（UUV）：随计算机、水下微光电视、水声定位导航、声纳成像、遥控技术发展而来。
- 本书第二编从控制技术角度分成**载人 / 不载人 / 双工（载人与不载人两用）**三类；无人又按有无脐带电缆分为**缆控（ROV）、无缆（AUV）、有缆无缆两用、细缆**四类。

#### 1.3 现状与展望
- 五六十年代发展慢（电子故障率高、通讯匹配、脐带电缆绞缠、起吊回收等未解决）。
- **转折点**：1966 年美国 CURV 打捞 868 m 深处氢弹；1975 年起近海石油开发 + 电子/计算机技术推动，水下机器人快速发展。
- **三大关键技术难题**：水下通讯、能源、控制。

### 第二章 水下机器人的结构

#### 2.1 定义
> 水下机器人是一种具有人的一部分或大部分功能、能在海洋环境下代替人进行某种作业的自动控制装置。靠电缆供电（有缆）或自身携带能源（无缆）驱动推进器作三维空间运动，可装设照明、摄像、声纳、传感器、机械手和作业工具。

#### 2.2 系统结构（三大部分）
1. **控制系统**：处理分析内外信息的综合系统，形成对载体的控制功能；最简单的由视频控制系统 + 运动/机械手指令反馈系统组成。
2. **观通系统**：用摄像机、照相机、照明、声纳及多种传感器收集外界与系统信息；经电缆（有缆）或水声通讯（无缆）与母船控制室传输。
3. **载体**：推进、能源、耐压结构等支撑部分。

> 观通系统要点：信息传输质量取决于照明光学器械、摄像机参数，最受影响的是**电缆参数与长度**（越长衰减越大）；水声通讯受海水温度、盐度、压力分布不均影响，水温对声速影响最大，且声波有折射、被吸收衰减，故水声通讯对无缆水下机器人有一定局限性。

#### 2.3 总体布置与设计要点
- 总体布置流程：方案设计（据技术任务书、排水量、重量、装置类型参数绘制总体布置图）→ 方案评审 → 分析论证 → 技术设计 → 施工设计。
- 考虑因素：最大化发挥装置性能、便于使用存放维护等。
- **没有完善设计准则**：因水下机器人多样性、未批量生产，设计依赖设计师经验、洞察力与才智；目标是在满足任务书前提下设计排水量与主尺度最小、性能最优的机器人。
- **设计程序**：提出设计任务书 → 绘制草图、总布置图、内部结构图 → 计算重量、排水量、浮性与稳性、壳体强度、运动阻力 → 求推进功率、航速 → 详细化 → 完成施工图纸。
- **设计方法**：母型设计法、逐渐近似法、方案法、系统法。

#### 2.4 重心与浮心、最佳性能准则
- 浮心坐标：$Z_c=\frac{\sum M_z'}{\sum V}$；稳心高 $h=Z_c-Z_g$。
- 平衡条件：$X_c=X_g$、$Y_c=Y_g$；若不相等需调整布置，使 $\text{tg}\,\varphi_0=\frac{X_c-X_g}{Z_c-Z_g}$，$\varphi_0=0°～1.5°$。
- **最佳性能准则**：目前优化理论未完全形成，仅能按用途选技术经济指标。观察型偏航速与自持力；作业型偏作业能力与工作状态自持力。
- 例：耐压壳密度 $\rho=\frac{W_c}{V_c}$——密度越低，越有利于减轻重量、增加有效载荷。

### 第三章 水下机器人能源与动力

#### 3.1 能源总体要求
> 必须**安全、可靠性好、容易控制、价格低廉、耐高压、耐低温、耐腐蚀、不污染环境**；单位重量、单位体积能量密度要高。

现有动力：**电力、电池、燃料电池、热动力装置、核动力装置**，按用途、形式、性能、使用条件选用。

#### 3.2 推进功率确定
- 阻力主要是**形状阻力**（排开水的空间占用，是截面与形状的函数）与**摩擦阻力**（表面与水的摩擦）。
- 有缆机器人形状各异、结构复杂，阻力多靠实测或参照母型；无缆机器人外形近流线型，可近似计算。
- 推进器轴功率近似公式：
$$N=\frac12 \cdot \frac{\rho \nu^3}{1000}\cdot \frac{C_x}{\eta}S$$
式中 $\rho$—水密度；$\nu$—航速；$C_x$—正面阻力系数；$\eta$—推进系统推进系数；$S$—横剖面面积。

#### 3.3 动力源
- **电力**：现代水下机器人主要能源，有缆靠电缆由水面供电，无缆靠蓄电池（化学式）或热/核能（物理式）。选电源考虑：总需要量、重量与体积、使用管理、维护修理、成本、脐带电缆尺寸性能。
- **电池**：化学式电源（电介质中正负电极间电子流动产生电能）。可充电的称**二次电池**，不可充电称一次电池。
  - 优点：结构简单、可在深海压力下工作（减轻耐压壳重量）、无运动部件无噪声振动、可在宽温度范围工作、安全可靠（单单元故障仍可继续工作）、市场可得。
  - 缺点：能量密度/比能量小，功率一般≤几十 W/kg、几千 W/m³（银锌电池除外）。
- **燃料电池**：H₂ + ½O₂ → H₂O，化学能直接变电能。美英法日均研制；比功率可达 50~60 W/kg。效率取决于燃料与氧化剂的紧凑、安全、长期存储装备设计。
- **机械换能式热动力装置**：将热能变电能，效率高。采用**闭式循环**（燃烧产物残留或溶于吸收剂）：燃烧室→热交换器→气体冷却器→返回燃烧室；燃气轮机按闭式绝缘路径（冷凝→热交换→升温→返回）。缺点：重量尺寸特性较差。
  - 实例：日本三井/东京大学"R-1"样机，采用封闭式柴油发动机（CCDE，9.56 kW 柴油机+发电机+CO₂吸收器+液氧容器+燃料罐等，排气管用氢氧化钾溶液处理），可连续潜航 12×10⁴ m，成本低易维护。
- **核动力装置**：利用放射物质衰变热 → 机械换能器 → 电能。半衰期数年至数十年，无需补燃料，最适长期潜航的无缆机器人。
- **推进器**：电机推进器、液压推进器、喷水推进器、磁流体推进器。

### 第四章 水下机器人的密封技术

#### 4.1 耐压结构设计
- **耐压壳体作用**：装电子元器件与检测设备，防海水压力与腐蚀；既是浮力主要提供者，重量又占整机很大比例。
- 壳体形状与材料取决于两个因素：**最大设计深度、有效载荷**。
- **球形壳体优势**：稳定性高、密度小，薄膜应力只有圆柱形的一半，工作深度 >800 m 多用球形；<800 m 依据应力确定的球形壳体薄且轻。
- 耐压壳体材料要求：考虑**腐蚀**（化学/电化学作用）与**应力腐蚀破裂**（裂纹+拉应力联合塑变扩大破坏）。
- 封头失稳校核：碟形封头球面部分按球壳校核；椭圆封头用当量半径 $R_i=K_1(D_i+S)$ 的球壳，$K_1$ 查表（随 $D_i/2h_i$ 减小而减小，约 0.50~1.18）。

#### 4.2 密封
- **可拆卸封头密封**：壳体装电子部件/仪器，作业后需检修，故须有可拆卸封头；关键在于可靠封闭两配合表面的间隙。
- **接触密封法**：在两表面间夹一个高机械强度、弹性好、恢复变形能力大的辅助元件，塞满间隙阻止海水进入。
- **水密接插件**：模压塑料接头（低压可用）；**水下可解脱接头**：氯丁橡胶模压阳插头/阴插座，利用公盈产生接合除水作用，海上插拔时漏泄电阻可超 100 MΩ。
- **动密封**：旋转轴用机械密封（端面密封），密封端面垂直于旋转轴线。用于推进器电机，不采用油补偿密封的电机需用动密封。

### 第五章 水下机器人常用材料与防腐

#### 5.1 常用材料
- 碳钢、合金钢、不锈钢、铜合金、铝合金、钛及钛合金、非金属材料。
- **碳钢**：便宜、供应方便、综合机械性能优良；但海洋环境腐蚀严重（受氯离子、导电性、氧含量、流速、温度、污染影响），需防腐与定期维护。
- **复合材料**：玻璃纤维树脂复合材料（非耐压壳体、浮力外壳）；碳纤维树脂复合材料相对密度更小、弹性模量高 4~5 倍，常包覆金属耐压壳外，可减小壁厚、减轻重量（但抗冲击差、横向/层间剪切强度低、易老化）。

#### 5.2 防腐蚀措施
1. 采用耐腐蚀金属、合金或非金属材料；
2. 将被保护表面与侵蚀介质隔绝（有机涂层：涂料/塑料；无机涂层：金属/非金属镀层）；
3. 电化学保护；
4. 减轻腐蚀的结构设计。
- 常用防锈漆：环氧沥青防锈漆、煤焦沥青防锈漆、氯化橡胶防锈漆。

#### 5.3 浮力材料
- 只用耐压壳体产生浮力会增大体积、重量和阻力，故其余浮力由**浮力材料**提供。
- **合成固体浮力材料**：填充材料（中空玻璃微球、树脂微球、碳微球）+ 粘结剂（环氧树脂）。
- 要求：密度≤0.7、不与水反应不溶吸水率低、能承受高静水压、体积弹性模量与海水相近或略高、不燃无毒。
- 玻璃微球+环氧树脂成形好（可浇注/机加工成任意形状），可调浮力及纵倾横倾；无缆机器人可用其构成流线型本体。
